# Employee Managemeny System EMS
We are creating an EMS that two type of persons can use:
## 1- Admin
The admin would be able to manage all the employees. He can:
- View a Dashboard
- Manage Employees Information
- Manage Leaves
- Manage Salary
## 2- User
The user would be able to :
- View a Dashboard
- View / Edit his profile
- Request for a Leave
